# Atividade: Encontre e Corrija os Erros

Você recebeu um projeto Python incompleto que simula um sistema de controle de estoque de loja. O código foi propositalmente alterado e contém erros que impedem seu funcionamento correto.

## O que você deve fazer

1.  Clone o projeto:
```   
git clone https://github.com/MMVonnSeek/dev-sistemas.git
```  
2.  procure pela pasta **encontre_o_erro** dentro de **modulo3-banco-com-python**

3.  Analise os arquivos do projeto fornecido.
    
4.  Identifique todos os erros presentes no código.
    
5.  Para cada erro encontrado, descreva:
    
       **a)** Em qual arquivo e linha o erro está localizado.
        
       **b)** Qual é o problema e porque ele causa falha.
        
       **c)** Como corrigi-lo (escreva a linha correta).
        

## Entrega

Responda em um documento de texto `docx`, `txt` ou qualquer outro de sua escolha. Não é necessário executar o código, a análise pode ser feita apenas lendo os arquivos.

> **Dica:** os erros envolvem configuração de banco de dados, definição de modelos e operações com a sessão do SQLAlchemy. Leia cada arquivo com atenção antes de responder.
